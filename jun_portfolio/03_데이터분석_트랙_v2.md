| 핵심 한 줄 | 결과 |

## 1. 문제 정의

> **왜 했나** — 마케팅 부서가 *"TikTok 효과 있다"* 정성 평가에 정량 근거 부족
> **무엇이 어려웠나** — 단순 평균 비교는 인플루언서 selection 통제 불가 → 인과 보강 필요

K-Beauty 브랜드의 미국 진출에서 흔히 듣는 조언은 *"TikTok 으로 입소문 나면 Amazon 매출도 따라온다"* 입니다. 그러나 실제 효과 크기는 합의된 수치가 없습니다. 마케팅 부서가 인플루언서 시딩(seeding, 신규 인플루언서에게 제품 보내 후기 유도) 에 예산을 얼마 써야 하는지, 어떤 인플루언서를 어떤 키워드로 골라야 하는지 — 이 질문에 답할 정량 근거가 부족했습니다.

문제는 단순히 *"K-Beauty 키워드를 쓴 영상의 평균 **ERV** 가 높다"* 는 비교만으로는 인과 효과로 보기 어렵다는 점이었습니다. 여기서 **ERV (Engagement Rate per View)** 는 *조회수 1건당 참여 (좋아요·댓글·저장 합) 가 얼마나 일어나는지* 를 보는 비율 — 가령 ERV 5%p 차이는 1만 조회마다 추가로 500 건의 참여가 발생한다는 의미입니다. (참고로 ERV 와 자주 혼동되는 ER (Engagement Rate) 은 *팔로워 기반* 참여율 — 본 프로젝트의 K-Premium 분석은 ERV 기준). K-Beauty 키워드를 쓰는 인플루언서들이 *원래부터* 인기 있는 사람들일 가능성을 통제해야 했습니다. 단순 OLS 회귀에 그치지 않고 **인과 추론까지 단계적으로 보강하는 분석 설계**가 필요했습니다.

## 2. 해결 방법

> **무엇을 했나** — Amazon 5 brand 1.2만 리뷰 + TikTok 56명 1,680 영상 수집 → 5단계 분석 파이프라인
> **핵심 의사결정 3개** — 두 데이터 결합 / 인과 보강 / 자기 비판 closed loop

먼저 데이터 수집부터 직접 했습니다. Amazon 5개 K-Beauty 브랜드(COSRX, PURITO, Beauty of Joseon, imfrom, Dr.Jart+) 의 제품·리뷰를 Selenium 으로 1.2만 건 수집했고, TikTok 영상은 K-Beauty / 일반 스킨케어 해시태그 기반으로 56명 인플루언서의 1,680 영상을 반자동 (CAPTCHA 통과는 수동) 수집했습니다.

분석 파이프라인 5단계:

| # | 단계 | 핵심 |
|---|---|---|
| ① | 그룹 분류 | `K-Beauty / Generic Skincare / Others` 3-그룹 — 같은 카테고리 안 비교 |
| ② | 지표 생성 | `ERV` 계산 + 윈저화 (winsorization, 상위 1% 임계치 cap) + 로그 변환 |
| ③ | 통제 회귀 | OLS + HC3 robust SE — **상한** 추정 |
| ④ | 인과 보강 | PSM (Propensity Score Matching) ATT — **하한** 추정 (보수적) |
| ⑤ | 환산 | 1만뷰 기준 + 시나리오 민감도 (참여당 100/300/1,000원) |

핵심 의사결정 3가지를 짚으면 다음과 같습니다.

### 2-1. 왜 두 데이터(Amazon + TikTok)를 같이 봤나 — 정성·행동 신호의 상호 보완

> **왜**: 한쪽만 보면 시장의 절반만 보임 (정성 vs 행동)
> **뭐**: LDA 토픽 모델로 양쪽 keyword 단위 매칭
> **효과**: 콘텐츠 메시지 ↔ 실제 구매 만족 일치 검증

Amazon 리뷰는 *사용 경험* 의 심층 표현(만족·불만·성분 호불호) 이고, TikTok 은 *인지·반응* 의 광범위 신호(조회·참여·해시태그) 입니다. LDA(Latent Dirichlet Allocation, 문서를 토픽 분포로 변환하는 비지도 학습 기법) 로 양쪽에서 토픽을 추출하고 같은 키워드 단위로 매칭하는 구조를 잡았습니다. *어떤 데이터를 쓰느냐 만큼 어떻게 연결하느냐가 인사이트를 결정한다* 는 걸 배운 결정이었습니다.

### 2-2. 왜 단순 OLS 가 아닌 PSM 까지 갔나 — **인과 보강의 단계적 접근**

> **왜**: 단순 회귀의 8.43%p 가 outlier 영향 받은 과대 추정
> **뭐**: 윈저화 99% + OLS HC3 (상한) + PSM ATT (하한) 단계 적용
> **효과**: 4.76 ~ 5.10%p 구간 robust 추정 / 신뢰구간 [2.46, 14.15] → [3.68, 6.35]

처음 단순 회귀만 돌렸을 때 K-Beauty 키워드 효과는 +8.43%p 가 나왔습니다. 그러나 신뢰구간이 [2.46, 14.15]로 매우 넓었고 (p<0.05 라도 추정 폭이 넓다는 뜻), TikTok 의 viral 특성상 ERV 상위 1% extreme(132% 등) 이 평균을 끌어올린 결과였습니다.

**Before / After — 인과 보강 단계별 효과 변화**:

| 단계 | 추정 | 신뢰구간 | 의미 |
|---|---:|---|---|
| 옛 단순 OLS (윈저화 X) | +8.43 %p | [2.46, 14.15] (넓음) | ❌ outlier 영향 과대 추정 |
| **윈저화 99% + OLS HC3** | **+5.10 %p** | [3.68, 6.35] (좁음) | ✅ **상한** (관찰 기반) |
| **PSM ATT (1:1 매칭)** | **+4.76 %p** | (부트스트랩 SE) | ✅ **하한** (보수적 인과) |

두 추정 차이가 0.34%p 미만이라 K-Beauty 효과는 **4.76 ~ 5.10%p 구간** 으로 robust 하다고 결론냈습니다. *단순 OLS 의 8.43 만 보고 결론냈다면 두 배 가까이 과대 추정한 권고를 했을 것* — 인과 보강이 분석가의 책임이라는 걸 직접 확인한 경험이었습니다 (자세한 수치 변천: [`docs/refactor/14_kpremium_number_history.md`](../docs/refactor/14_kpremium_number_history.md)).

### 2-3. 왜 추천 알고리즘을 4번 진화시켰나 — **자기 비판 closed loop**

> **왜**: K-Beauty 효과가 인플루언서 selection 에 의존 → 인플루언서 자동 선정이 직접 솔루션
> **뭐**: 초기 단순 알고리즘 → ER% 가중치 추가 → 안전장치 추가 → 재구현 (총 4 번 반복)
> **효과**: 평균 1.25× → 3.25× random ERV (10,000 부트스트랩 검증)

K-Beauty 효과가 인플루언서 selection (누가 만드는가) 에 크게 의존한다는 점을 확인했기 때문에, 인플루언서를 자동으로 선정하는 추천 알고리즘이 직접적인 솔루션이라고 봤습니다.

알고리즘 진화 4 단계:

| 버전 | 핵심 차이 | 의도 |
|---|---|---|
| 1차 (ver.1) | TF-IDF cosine similarity 기본 — 콘텐츠 토픽 매칭만 | 콘텐츠 유사 인플루언서 추천 |
| 2차 (ver.2) | + ER% 가중치 (단어 반복 횟수 = ER%×3) | 효율 좋은 인플루언서 우선 |
| **3차 (ver.3)** | + `max(1, ...)` 안전장치 (가중치 0 방지) | edge case 방어 |
| **4차 (ver.4)** | TF inflation 제거 + score 단계 연속 가중치 (`sim × (ER%+0.1)`) | 3차의 한계 발견 후 재구현 |

용어 풀이:
- **TF-IDF** (Term Frequency-Inverse Document Frequency): 문서별 단어 중요도 가중치 — 흔한 단어(`the`)는 낮게, 그 문서 특이 단어는 높게.
- **cosine similarity**: 두 벡터의 방향이 얼마나 비슷한지 (-1~1, 1에 가까울수록 비슷).
- **TF inflation**: 한 단어를 N번 반복해서 가중치를 표현하는 기법. 단순하지만 vocabulary 폭발 + 정보 손실 위험.
- **score 단계 가중치**: TF-IDF 후 cosine 결과에 직접 곱셈으로 가중치 적용.

3차 (ver.3) 결과를 stability 검증 — *모든 가능한 인플루언서 조합 1,540 pair* 비교 — 했더니 단일 selected 결과(2.32× random)가 lucky case 였고 평균은 무작위 대비 **1.25× 에 그쳤습니다**.

**Mechanism 분해 (왜 약했나)**: ER% 가중치 (`int(round(normalized_ER × 3))`) 가 의도와 달리 작동 안 함 → 56명 중 **47명(84%)** 이 가중치 0이 되어 `max(1, ...)` 안전장치로 모두 동일한 (1,1,1) 가중치 → 3차가 사실상 2차와 동일한 알고리즘이었음.

이 한계를 발견 한 뒤 4차 (ver.4) 에서 TF inflation 을 제거하고 score 단계의 연속 가중치 곱셈으로 재구현 → 정량 검증 결과:

| Metric | 3차 (ver.3) | **4차 (ver.4)** | 개선 |
|---|---:|---:|---:|
| 1,540 pair 평균 ERV | 15.0 | **39.1** | +24.1 |
| × random (10,000 부트스트랩) | 1.25× | **3.25×** | — |
| > random 비율 | 61.4% | **100%** | — |
| Precision@10 (실제 ERV 상위 10명 중 추천 일치) | 20% | **60%** | — |

Paired t-test (v4 - v3): t=122.80, p<0.0001 — 모든 selected 조합에서 4차가 3차 능가. *자기 비판 → 개선 → 정량 검증* 의 closed loop 으로 알고리즘 신뢰도를 직접 입증한 경험이었습니다.

## 3. 프로젝트 결과

> **K-Premium**: +4.76 ~ 5.10 %p, 1만뷰당 47,600 ~ 51,000원
> **추천 알고리즘**: 무작위 대비 3.25× ER% (Top-10), Precision@10 60%
> **Robustness**: 두 인과 추정 차이 0.34%p, 모든 selected 조합에서 ver.4 우위

K-Beauty 해시태그 효과는 통제 회귀와 인과 보강 양쪽에서 일관되게 나왔습니다.

- 🔝 **OLS HC3 (상한)**: 조회수·팔로워 통제 후 **+5.10 %p (p<0.05)**, CI [3.68, 6.35]
- 🔻 **PSM ATT (하한)**: 영상 특성 1:1 매칭 후 **+4.76 %p (p<0.05)**, 부트스트랩 SE
- 💰 **1만뷰 환산**: 47,600 ~ 51,000원 (CPE 100원 가정. 시나리오 민감도 100/300/1,000원 동시 제공)

재구현 알고리즘 (4차) 은 1,540개 selected 조합으로 stability 검증해서 무작위 대비 **3.25× ERV** (Top-10), **Precision@10 60%**, paired t-test t=122.80 (p<0.0001) 의 정량 결과를 얻었습니다.

## 4. 프로젝트 회고

> **배운 점**: 분포 점검부터 시작하는 습관 + 알고리즘 의도 ≠ 실제 작동의 정량 검증
> **한계**: within-FE 추가 발견 (selection 95%) — 키워드 자체 marginal 효과는 미미

### 배운 점

대표적인 두 사례가 있습니다.

**① 윈저화 적용 여부에 따라 효과가 8.43→5.10%p 로 달라진 일** — TikTok 데이터의 viral 특성상 ERV 가 100%를 넘는 영상이 1% 정도 섞여 있었는데, 그게 평균을 끌어올려 단순 OLS 결과를 과대 추정했습니다. 윈저화 99% (상위 1% 임계치 cap) 한 뒤 신뢰구간이 [3.68, 6.35]로 좁아졌습니다. *데이터 분포의 꼬리부터 보는 습관* 이 그때 생긴 것입니다.

**② 추천 알고리즘 3차 버전의 가중치가 의도대로 작동하지 않은 일** — 56명 중 47명(84%)의 가중치가 0이 되어 동일한 (1,1,1) 가중치로 평준화됐습니다. 즉 3차 = 2차와 사실상 같은 알고리즘. 4차 (재구현) 에서 score 단계의 연속 가중치 곱셈으로 바꾸니 1,540 pair 평균 1.25× → 3.25× random 으로 정량 개선됐습니다. *알고리즘의 의도와 실제 작동을 정량으로 분리해서 검증* 하는 게 분석가의 기본 책임이라는 걸 그때 배웠습니다.

### 한계

추가 검증 (within-influencer fixed effect, 인플루언서 고유 특성을 통제하는 회귀 기법) 결과 K-Beauty 키워드 자체의 효과는 **+0.24 %p (p=0.75, 통계적 유의 X)** 로 떨어졌습니다 — 즉 OLS·PSM 의 4.76~5.10%p 효과의 약 95% 가 *인플루언서 selection effect* (특정 그룹에 원래부터 인기 있는 사람이 몰린 편향) 라는 추가 발견입니다.

**해석**: OLS·PSM 결과는 *"인플루언서 신규 시딩 시 K-Beauty 인플루언서 vs Generic Skincare 인플루언서"* 비교 효과 (마케팅 의사결정 관점, 4.76~5.10%p 유효) / within-FE 결과는 *"같은 인플루언서가 K-Beauty 키워드 추가 시"* marginal 효과 (키워드 자체의 한계 효과). 두 결과를 분리해서 해석해야 합니다 — 자세한 가이드: [`docs/refactor/14_kpremium_number_history.md`](../docs/refactor/14_kpremium_number_history.md).

또 단일 시점·단일 데이터셋(2024.12 수집) 이라 다른 기간으로 일반화하려면 추가 수집이 필요합니다. TikTok 데이터는 CAPTCHA·로그인 등 플랫폼 보안으로 완전 자동 수집이 어려워 표본 크기 확장 자체가 비용입니다.

## 5. 이 프로젝트로 얻은 것

> 비즈니스 질문 → 데이터 가설 → 인과 추정 → 정량 환산 → 액션 알고리즘 → robustness 검증 의 **한 사이클** 직접 실행

이번 프로젝트로 데이터 분석가 직무의 핵심 흐름을 처음부터 끝까지 한 번 다뤄봤습니다. K-Beauty 라는 비즈니스 개념을 ERV 라는 측정 가능한 지표로 옮기고, OLS·PSM 으로 효과 구간을 산출한 뒤, 인사이트를 인플루언서 시딩 추천 알고리즘으로 자동화했습니다. 마지막에는 1,540 selected pair stability 검증으로 알고리즘 자체의 robustness 까지 정량 입증했습니다.

데이터 분석가 직무에서 가장 중요한 건 *통계적 효과를 그대로 권고로 옮기지 않고, 인과 보강과 robustness 검증으로 의사결정의 신뢰도를 직접 끌어올리는* 일이라고 봅니다. 이번에 그 흐름을 한 번 끝까지 돌려본 만큼, 다른 도메인의 비즈니스 질문에도 같은 방식으로 접근할 수 있다고 봅니다.

특히 어떤 분포의 데이터를 어떻게 다듬을지 (윈저화), 어떤 confounder 를 어떻게 통제할지 (PSM), 자기 알고리즘의 한계를 어떻게 정량으로 발견할지 (stability 검증) — 이 세 가지는 어떤 도메인의 데이터를 다뤄도 공통으로 필요한 분석가의 기본기라고 봅니다.

**Hard skills**

- 📊 통계·인과 추정: Python, Pandas, NumPy, scikit-learn, **statsmodels** (회귀·인과 추정), **gensim** (LDA), nltk·spaCy (NLP)
- 🤖 추천 알고리즘: TF-IDF + cosine similarity, **PMI** (Pointwise Mutual Information), MinMax 정규화, **부트스트랩 stability 검증** (10,000회)
- 🕷 데이터 수집: **Selenium** (Amazon 1.2만 건), TikTok 반자동 (CAPTCHA 수동)
- 🛢 DB·인프라: MySQL (SQLAlchemy upsert), Slack 모니터링, Docker
- 🧠 LLM·지식그래프: **GraphRAG** (LanceDB + Ollama·OpenAI), pyLDAvis 시각화

**Soft skills (협업 중심)**

- 5명 팀의 분석 파트로 **인과 추정·추천 알고리즘 진화 주도**
- 단순 OLS 결과(8.43%p) 에 만족하지 않고 PSM 까지 보강한 뒤 팀에 *효과 구간(4.76~5.10%p)* 으로 보고 → **과대 추정 위험을 팀 의사결정 단계에서 차단**
- 추천 알고리즘 ver.3 한계를 직접 발견·문서화하고 ver.4 로 재구현 → **자기 비판 가능한 분석가**
- 분석 결과를 노션 페이지로 정리해 팀·발표자에게 전달 (가설 H1~H4 → 검증 결과 → 마케팅 시사점 흐름)

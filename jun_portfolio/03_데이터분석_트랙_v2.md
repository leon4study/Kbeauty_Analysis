# K-Beauty 미국 시장 진출 전략 분석 - 김현준

| 기간 | 역할 | 팀 | 결과 |
| --- | --- | --- | --- |
| 2024.12.17 ~ 2024.12.27 (2주) | 팀원 : 인과 추정·추천 알고리즘 담당 | 5명 (분석 4, 발표 1) | K-Beauty 키워드 ERV 프리미엄 +4.76~5.10%p (1만뷰당 47,600~51,000원) |

## "단순 회귀로 +8.43%p 가 나왔지만, 인과 추정 단계를 더 거쳐 +4.76~5.10%p 로 더 정확한 구간으로 좁혔습니다"

K-Beauty 마케팅 부서가 *"TikTok 입소문 → Amazon 매출"* 이라는 정성 평가에 의존해 왔는데, 이 효과를 측정 가능한 숫자로 바꾸는 게 분석 목적이었습니다. ERV(조회수 1건당 좋아요·댓글·저장이 얼마나 일어나는지를 보는 비율) 라는 지표로 K-Beauty 효과를 추정한 결과 처음엔 +8.43%p가 나왔는데, 데이터 분포를 다시 점검하고 매칭 기반 인과 추정을 추가하면서 +4.76~5.10%p 구간으로 좁혀졌습니다. 이 효과를 마케팅 시점에 자동 활용할 수 있도록 인플루언서 추천 알고리즘도 직접 만들었고, 알고리즘이 의도대로 작동하는지 1,540개 조합으로 확인하면서 한계를 발견해 재구현까지 거쳤습니다. 5명 팀의 분석 파트로 인과 추정과 추천 알고리즘 부분을 담당했습니다.

---

## 1. 문제 정의 — "‘TikTok 효과 있다’를 정량값으로 옮기기"

K-Beauty 브랜드의 미국 진출에서 *"TikTok 으로 입소문 나면 Amazon 매출도 따라온다"* 는 조언은 자주 들리지만 합의된 수치는 없었습니다. 마케팅 부서가 인플루언서 시딩(신규 인플루언서에게 제품을 보내 후기를 유도하는 마케팅) 에 예산을 얼마 써야 하는지, 어떤 인플루언서를 어떤 키워드로 골라야 하는지 — 이 질문에 답할 정량 근거가 필요했습니다.

문제는 단순히 *"K-Beauty 키워드가 들어간 영상의 ERV 가 높다"* 는 비교만으로는 인과 효과로 보기 어렵다는 점이었습니다. K-Beauty 키워드를 쓰는 인플루언서들이 *원래부터* 인기 있는 사람들일 가능성을 통제해야 했고, ERV 분포에 끼어 있는 1% 정도의 극단값(viral 영상) 이 평균을 끌어올리는 효과도 분리해야 했습니다. 단순 OLS 회귀에 그치지 않고 매칭 기반 인과 추정까지 거치는 분석 설계가 필요했습니다.

## 2. 해결 방법 — "두 데이터를 묶고, 회귀 → 매칭 → 알고리즘으로 단계를 쌓았습니다"

먼저 데이터부터 직접 모았습니다. Amazon 5개 K-Beauty 브랜드(COSRX, PURITO, Beauty of Joseon, imfrom, Dr.Jart+) 의 제품·리뷰를 Selenium 으로 1.2만 건 수집했고, TikTok 영상은 K-Beauty 와 일반 스킨케어 해시태그를 기준으로 56명 인플루언서의 1,680 영상을 반자동(CAPTCHA 통과는 수동) 수집했습니다.

분석 파이프라인은 다섯 단계로 짰습니다.
① K-Beauty / 일반 스킨케어 / 그 외 세 그룹으로 분리해 같은 카테고리 안에서 비교
② ERV 계산 + 상위 1% 극단값 처리(윈저화) + 로그 변환
③ 통제 회귀(OLS) — 조회수·팔로워 영향을 빼고 본 키워드 효과 추정
④ 매칭 기반 인과 추정(PSM) — 영상 특성이 비슷한 K-Beauty 영상과 일반 스킨케어 영상을 1:1로 짝지어 비교
⑤ 1만뷰 기준 가치 환산 + 시나리오 민감도(참여 1건당 100/300/1,000원)

실행 과정에서 가장 중요한 의사결정 세 가지를 짚으면 다음과 같습니다.

### 2-1. 왜 Amazon 리뷰와 TikTok 영상을 같이 봤나 — 한쪽만 보면 시장의 절반만 보임

Amazon 리뷰는 *"실제로 써보니 어땠다"* 는 만족·불만의 심층 표현이고, TikTok 은 *"눈에 띄어서 반응한다"* 는 인지·관심의 광범위 신호입니다. 한쪽만 보면 구매 만족과 인지 반응 중 하나만 보는 셈이라, 두 데이터를 LDA 토픽 모델(문서를 토픽 분포로 변환하는 비지도 학습 기법) 로 같은 키워드 단위에서 매칭하는 구조로 잡았습니다. 어떤 데이터를 쓰느냐 만큼 어떻게 연결하느냐도 인사이트의 크기를 결정한다는 걸 배운 결정이었습니다.

### 2-2. 왜 단순 회귀에서 멈추지 않고 PSM까지 갔나 — 8.43%p 과대 추정을 4.76~5.10%p 구간으로 좁히기 위해

처음 단순 회귀만 돌렸을 때 K-Beauty 키워드 효과는 +8.43%p가 나왔습니다. 그런데 신뢰구간이 [2.46, 14.15]로 매우 넓었고(p<0.05라도 추정 폭이 그만큼 넓다는 뜻), TikTok 의 viral 특성상 ERV 가 100%를 넘는 영상이 1% 정도 끼어 있어 그게 평균을 끌어올린 결과였습니다.

ERV 의 상위 1%를 임계치로 자르는 윈저화를 적용한 뒤 OLS 의 표준오차를 분산 불균형까지 보정해주는 HC3 방식으로 다시 추정했더니 **+5.10%p (상한)** 으로 안정됐습니다. 여기에 더해, 영상 특성(조회수·팔로워·업로드 주기) 이 비슷한 K-Beauty 영상과 일반 스킨케어 영상을 1:1로 매칭하는 PSM(Propensity Score Matching) 으로 처치군의 평균 효과(ATT) 를 구하니 **+4.76%p (하한)** 가 나왔습니다.

| 단계 | 추정 | 신뢰구간 | 의미 |
|---|---:|---|---|
| 단순 OLS (윈저화 미적용) | +8.43 %p | [2.46, 14.15] | 1% 극단값 영향 받은 과대 추정 |
| 윈저화 + OLS HC3 | +5.10 %p | [3.68, 6.35] | 상한 추정 |
| PSM 매칭 후 ATT | +4.76 %p | (부트스트랩) | 보수적 인과 추정 (하한) |

두 추정의 차이가 0.34%p 미만이라 K-Beauty 효과는 4.76 ~ 5.10%p 구간으로 안정적이라고 결론 냈습니다. 단순 OLS의 8.43%p만 보고 결론냈다면 두 배 가까이 과대 추정한 권고를 했을 것이라, 매칭 기반 인과 추정까지 거치는 게 분석가로서 해야 하는 일이라는 걸 그때 배웠습니다 (자세한 수치 변천: [`docs/refactor/14_kpremium_number_history.md`](../docs/refactor/14_kpremium_number_history.md)).

추가로 같은 인플루언서가 K-Beauty / 그 외 영상을 모두 만든 경우만 비교하는 within-influencer fixed effect 까지 돌렸더니 K-Beauty 키워드 자체의 효과는 +0.24%p (p=0.75, 통계적 유의 X) 로 떨어졌습니다. 즉 OLS·PSM 의 4.76~5.10%p 효과의 약 95%는 *원래부터 ERV 가 높은 인플루언서들이 K-Beauty 키워드를 쓰는 데서 오는 효과* 라는 점이 보였습니다. *키워드 자체의 마진* (인플루언서 신규 시딩 시) 4.76~5.10%p, *키워드 단독 효과* (같은 인플루언서가 키워드 추가 시) 0.24%p — 두 결과를 분리해서 해석해야 한다는 게 본 분석의 핵심 인사이트였습니다.

### 2-3. 추천 알고리즘을 네 번에 걸쳐 개선한 경험 — 조합 검증에서 발견한 한계를 보완해 성능 향상

K-Beauty 효과가 *어떤 인플루언서가 만드느냐* 에 크게 의존한다는 점을 분석에서 확인했기 때문에, 인플루언서 자동 선정 알고리즘이 본 분석의 직접적인 솔루션이라고 봤습니다.

처음 만든 알고리즘은 콘텐츠 토픽(LDA top3 태그) + 인플루언서 효율(ER%) 가중치를 결합한 TF-IDF (Term Frequency-Inverse Document Frequency, 문서별 단어 중요도 가중치) + cosine 유사도 기반이었습니다. 결과를 1,540개 조합 (56명 중 2명을 기준 인플루언서로 뽑는 모든 경우의 수) 으로 확인해보니 처음에 본 단일 결과(무작위 대비 2.32배) 가 운 좋게 잘 나온 케이스였고, 1,540개 평균은 무작위 대비 1.25배에 그쳤습니다.

원인을 자세히 살펴보니, ER% 가중치(`int(round(normalized_ER × 3))`) 가 의도와 다르게 작동했습니다. 56명 중 47명(84%) 이 가중치가 0이 되어 안전장치 `max(1, ...)` 발동으로 모두 동일한 (1,1,1) 가중치가 됐고, 결과적으로 ER% 가중치가 거의 작동 안 한 셈이었습니다.

이 부분을 보완해서 단어 반복 방식 대신 점수를 계산할 때 직접 ER% 를 곱하는 방식 (`score = sim × (ER% + 0.1)`) 으로 다시 만들었습니다. 처음 만든 알고리즘 vs 다시 만든 알고리즘 정량 비교:

| 지표 | 처음 만든 알고리즘 | 다시 만든 알고리즘 | 개선 |
|---|---:|---:|---:|
| 1,540 조합 평균 ERV | 15.0 | 39.1 | +24.1 |
| 무작위 대비 (10,000회 부트스트랩) | 1.25배 | 3.25배 | — |
| 무작위 평균 이상 비율 | 61.4% | 100% | — |
| 정확도 Precision@10 | 20% | 60% | — |

같은 selected 짝 비교(paired t-test) 에서 t=122.80, p<0.0001 — 1,540개 조합 모두에서 다시 만든 쪽이 더 잘 나왔습니다. 이 한계를 발견한 뒤 원인을 분석하고 다시 만들었습니다. 수집부터 마케팅 효과 계산까지 분석 전 과정을 직접 다뤄본 첫 큰 작업이었습니다.

## 3. 프로젝트 결과 — K-Premium +4.76~5.10%p · 1만뷰당 47,600~51,000원, 추천 알고리즘은 무작위 대비 3.25배

K-Beauty 해시태그 효과는 통제 회귀와 인과 보강 양쪽에서 일관되게 나왔습니다.

- 통제 회귀(OLS HC3, 상한): 조회수·팔로워를 통제한 후 +5.10%p (p<0.05), 신뢰구간 [3.68, 6.35]
- 매칭 기반 인과 추정(PSM, 하한): 영상 특성 1:1 매칭 후 +4.76%p (p<0.05)
- 1만뷰 환산: 참여 1건당 100원 가정 시 1만뷰당 47,600 ~ 51,000원의 추가 가치 (시나리오 민감도 100/300/1,000원도 같이 제공해 마케팅 부서가 자체 단가로 재환산할 수 있게 함)

최종 알고리즘은 1,540개 조합으로 확인한 결과 무작위 대비 3.25배 ERV(Top-10 기준), 정확도 Precision@10 60% 였습니다.

### 마케팅 권고 액션 (분석 결과 → 실무 적용)

분석 결과를 바탕으로 마케팅 부서가 바로 적용할 수 있는 권고를 정리했습니다.

- **신규 인플루언서 시딩 시 K-Beauty 키워드 사용자 우선** — 4.76~5.10%p 효과가 인플루언서 selection 에 의존하므로, 같은 카테고리 안에서 *이미 K-Beauty 콘텐츠를 만든 적 있는* 인플루언서를 시딩 풀에 우선 포함
- **세그먼트별 차별 접근 권장** — 추천 알고리즘 결과를 마이크로(10K-100K), 미들(100K-500K), 매크로(>1M) 로 분리해 캠페인 목표(인지도/전환/Brand awareness)에 맞춰 운영
- **1만뷰당 47,600~51,000원** 은 ERV (참여 행동) 기준 하한 추정 — Amazon 실제 매출 funnel 까지 가는 conversion 은 별도 측정 필요. *참여 → 검색 → Amazon 구매* 의 추적 데이터가 추가되면 ROAS / CAC 같은 표준 KPI 환산 가능

### 한계

본 분석의 한계는 두 가지입니다.

첫째, 단일 시점·단일 데이터셋(2024.12 수집) 이라 다른 기간으로 일반화하려면 추가 수집이 필요합니다. TikTok 데이터는 CAPTCHA·로그인 등 플랫폼 보안으로 완전 자동 수집이 어려워 표본 크기 확장 자체가 비용입니다.

둘째, ERV (참여) 가 *직접 매출* 이 아닌 *관심·반응 신호* 까지만 측정합니다. TikTok → Amazon 로 가는 attribution (구매 출처 추적) 데이터가 없어 1만뷰당 47,600~51,000원은 *참여 가치를 마케팅 비용으로 환산했을 때의 비교 기준* 까지가 한계입니다.

## 4. 프로젝트 회고 — 분석 단계마다 직접 확인하면서 배운 것

이번 프로젝트에서 가장 컸던 경험은 *통계적으로 유의한 효과 = 인과 효과* 가 아니라는 걸 분석 단계마다 직접 확인한 것이었습니다.

### 배운 점

대표적인 두 사례가 있습니다.

첫 번째는 **윈저화 적용 여부에 따라 효과가 8.43%p에서 5.10%p로 달라진 일** 이었습니다. TikTok 데이터의 viral 특성상 ERV 가 100%를 넘는 영상이 1% 정도 섞여 있었는데, 그게 평균을 끌어올려 단순 OLS 결과를 부풀리고 있었습니다. 윈저화로 상위 1%를 임계치 값으로 처리한 뒤 신뢰구간이 [3.68, 6.35]로 좁아지고 추정도 안정됐습니다. 데이터의 극단값을 먼저 봐야 한다는 걸 그때 제대로 체감했습니다.

두 번째는 **처음 만든 추천 알고리즘의 가중치가 의도대로 작동하지 않은 일** 입니다. 56명 중 47명(84%) 의 가중치가 0이 되어 모두 동일한 (1,1,1) 가중치로 평준화돼서, ER% 가중치가 거의 작동 안 한 상태였습니다. 점수 계산 단계에서 ER% 를 직접 곱하는 방식으로 다시 만드니 1,540 조합 평균이 1.25배에서 3.25배로 올라갔습니다. *알고리즘이 의도대로 작동하는지 작동 방식까지 직접 확인해야 한다* 는 걸 그때 배웠습니다.

### 분석 한계 (정직히 명시)

본 분석의 한계 두 가지는 §3 마지막에 정리했고, 데이터 적용 측면에서 추가로 의식한 한계는 아래 두 가지입니다.

- **추천 알고리즘 평가 metric 보강 여지**: 본 분석은 1만뷰당 ERV 평균과 Precision@10 으로 평가했지만, NDCG·MAP·HitRate 같은 ranking quality 표준 metric 도 같이 보면 알고리즘 우위를 더 robust 하게 입증 가능. 후속에서 추가 적용 예정.
- **추천 풀 크기**: 본 데이터의 인플루언서 56명은 작은 규모. 실제 KOL 캠페인은 수백~수천명 풀에서 추천이 의미 — 데이터 확장 후 알고리즘 scaling 검증 필요.

모르는 부분을 모른다고 적어두는 것이 다음 분석에서 같은 추정 함정을 반복하지 않는 출발점이라고 봤습니다.

## 5. 이 프로젝트로 얻은 것

이번 프로젝트로 데이터 분석가가 한 사이클로 다루는 흐름 — *비즈니스 질문 → 측정 가능한 지표로 변환 → 인과 추정 → 정량 환산 → 액션 알고리즘 → 결과 확인* — 을 처음부터 끝까지 한 번 다뤄봤습니다. K-Beauty 라는 비즈니스 개념을 ERV 라는 측정 가능한 지표로 옮기고, 회귀와 매칭으로 효과 구간을 산출한 뒤, 그 결과를 인플루언서 시딩 추천 알고리즘으로 자동화했습니다. 마지막에는 1,540개 조합으로 알고리즘이 안정적으로 작동하는지까지 정량으로 확인했습니다.

데이터 분석가가 하는 일에서 가장 중요한 건 통계적으로 유의한 결과를 그대로 권고로 옮기지 않고, 인과 추정과 결과 일관성 확인까지 거쳐 의사결정의 신뢰도를 끌어올리는 일이라고 봅니다. 이번에 그 흐름을 한 번 끝까지 돌려본 만큼, 다른 도메인의 비즈니스 질문에도 같은 방식으로 접근할 수 있다고 봅니다.

특히 — 데이터의 극단값부터 점검하기, 매칭 기반 인과 추정을 한 단계 더 거치기, 알고리즘이 의도대로 작동하는지 구체적으로 확인하기 — 이 세 가지는 어떤 도메인의 데이터를 다뤄도 공통으로 필요한 분석가의 기본기라고 봅니다.

## 6. 사용 기술과 본인 직접 구현 부분

**본인이 직접 설계·구현한 것 (5명 팀 분담 명시)**

- 데이터 수집·크롤러: Selenium 으로 Amazon 5 brand 1.2만 건 직접 크롤링, TikTok 56명 1,680 영상 반자동 수집 (CAPTCHA 수동 통과 포함)
- DB·인프라: MySQL 스키마 직접 설계 + SQLAlchemy upsert 로직 본인 작성, Slack 모니터링 봇 연결, Docker 환경 구성
- 인과 추정: 윈저화 + OLS HC3 + PSM ATT + within-influencer fixed effect 까지 4 단계 회귀 본인 작성 (statsmodels)
- 추천 알고리즘: TF-IDF + cosine 유사도 + ER% 가중치 결합 → 1,540 조합 부트스트랩 검증 → 한계 발견 후 다시 구현
- LLM·지식그래프: GraphRAG (LanceDB + Ollama·OpenAI) 환경 본인 구성, pyLDAvis 토픽 시각화

**팀원 분담 (본인 외)**: 분석 결과 시각화 (대시보드 일부), 발표 자료 디자인, 일부 토픽 라벨링 검수

**Hard skills**: Python · Pandas · NumPy · scikit-learn · statsmodels · gensim · nltk · spaCy · Selenium · MySQL · SQLAlchemy · Docker · GraphRAG · LanceDB

**Soft skills (협업 중심)**

- 단순 OLS (8.43%p) 에서 멈추지 않고 PSM·within-FE 까지 거친 뒤 팀에 효과 구간(4.76~5.10%p) 과 selection 효과(95%) 분리해서 보고 — 팀 의사결정 단계에서 과대 추정 차단
- 처음 만든 추천 알고리즘의 한계를 직접 발견 + 문서화한 뒤 다시 만들어 정량 개선 입증
- 분석 결과를 노션 페이지로 정리해 팀과 발표자에게 전달 (가설 → 검증 → 마케팅 시사점 흐름)

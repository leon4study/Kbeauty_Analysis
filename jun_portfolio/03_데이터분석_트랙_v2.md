# K-Beauty 미국 시장 진출 전략 분석 - 김현준

| 기간 | 역할 | 팀 | 결과 |
| --- | --- | --- | --- |
| 2024.12.17 ~ 2024.12.27 (2주) | 팀원 : 인과 추론·추천 알고리즘 주도 | 5명 (분석 4, 발표 1) | K-Beauty 키워드 ERV 프리미엄 +4.76~5.10%p (1만뷰당 47,600~51,000원) |

## "단순 OLS 결과만 봤다면 +8.43%p 과대 추정으로 마케팅 권고를 했을 겁니다 — PSM 인과 보강으로 +4.76~5.10%p 구간을 산출했고, 추천 알고리즘은 자기 비판으로 ver.4까지 진화시켜 무작위 대비 3.25배 ER%를 입증했습니다"

마케팅 부서가 *"TikTok 입소문이 Amazon 매출을 만든다"* 는 정성 평가에 의존하는 의사결정에, 인과 추론(OLS HC3 → PSM ATT)으로 K-Beauty 키워드 ERV 프리미엄을 +4.76~5.10%p 구간으로 산출하고 1만뷰당 47,600~51,000원의 정량 가치로 환산했습니다. 5명 팀의 분석 파트로 인과 추정과 인플루언서 시딩 추천 알고리즘 진화를 주도했고, 알고리즘은 직접 stability 검증으로 ver.3의 한계를 발견한 뒤 ver.4로 재구현해 무작위 대비 3.25배 효과를 정량 입증했습니다.

---

## 1. 문제 정의 — "‘TikTok이 효과 있다’는 정성 평가를, 인과 추정으로 정량값까지 끌어내려 했습니다"

K-Beauty 브랜드의 미국 진출에서 흔히 듣는 조언은 *"TikTok 으로 입소문 나면 Amazon 매출도 따라온다"* 입니다. 그러나 실제 효과 크기는 합의된 수치가 없습니다. 마케팅 부서가 인플루언서 시딩(seeding)에 예산을 얼마 써야 하는지, 어떤 인플루언서를 어떤 키워드로 골라야 하는지 — 이 질문에 답할 정량 근거가 부족했습니다.

문제는 단순히 "K-Beauty 키워드를 쓴 영상의 평균 ERV (Engagement Rate per View, 조회수 대비 좋아요·댓글·저장 합) 가 높다" 는 비교만으로는 인과 효과로 보기 어렵다는 점이었습니다. K-Beauty 키워드를 쓰는 인플루언서들이 *원래부터* 인기 있는 사람들일 가능성을 통제해야 했습니다. 단순 OLS 회귀에 그치지 않고 인과 추론까지 단계적으로 보강하는 분석 설계가 필요했습니다.

## 2. 해결 방법 — "두 데이터를 한 의사결정으로 묶고, 단순 회귀 → 인과 보강 → 자동화 알고리즘으로 단계를 쌓았습니다"

먼저 데이터 수집부터 직접 했습니다. Amazon 5개 K-Beauty 브랜드(COSRX, PURITO, Beauty of Joseon, imfrom, Dr.Jart+) 의 제품·리뷰를 Selenium 으로 1.2만 건 수집했고, TikTok 영상은 K-Beauty / 일반 스킨케어 해시태그 기반으로 56명 인플루언서의 1,680 영상을 반자동 수집했습니다.

분석 파이프라인은 5단계로 설계했습니다.

① 그룹 분류 — `K-Beauty / Generic Skincare / Others` 3-그룹으로 분리해 *같은 카테고리(스킨케어) 안에서 K-Beauty의 추가 효과* 만 분리해 측정
② 지표 생성 — `ERV` 계산 + 윈저화(상위 1% 캡) + 로그 변환 (`log_view`, `log_follower`)
③ 통제 회귀 (OLS, HC3 robust SE) — 조회수·팔로워 통제 후 K-Beauty 효과 (관찰 기반 상한)
④ 인과 보강 (PSM ATT) — 영상 특성(`log_follower, log_view, upload_gap`) 이 비슷한 K-Beauty vs Generic Skincare 1:1 매칭 후 ATT (보수적 인과 추정 하한)
⑤ 1만뷰 기준 금액 환산 + 시나리오 민감도 (참여당 100/300/1,000원)

실행 과정에서 가장 중요한 의사결정 세 가지를 짚으면 다음과 같습니다.

### 2-1. 왜 두 데이터(Amazon + TikTok)를 같이 봤나 — 정성·행동 신호의 상호 보완

Amazon 리뷰는 *사용 경험* 의 심층 표현(만족·불만·성분 호불호) 이고, TikTok 은 *인지·반응* 의 광범위 신호(조회·참여·해시태그) 입니다. 한쪽만 보면 시장의 절반만 보는 셈이라, 두 데이터를 토픽·키워드 단위로 연결해서 *어떤 콘텐츠 메시지가 실제 구매 만족과 일치하는지* 검증하는 구조로 설계했습니다.

LDA(Latent Dirichlet Allocation, 문서를 토픽 분포로 변환하는 비지도 학습 기법) 로 양쪽에서 토픽을 추출하고 같은 키워드 단위로 매칭하는 구조를 잡았습니다. *어떤 데이터를 쓰느냐 만큼 어떻게 연결하느냐 가 인사이트를 결정한다* 는 걸 배운 결정이었습니다.

### 2-2. 왜 단순 OLS 가 아닌 PSM 까지 갔나 — 인과 보강의 단계적 접근

처음 단순 회귀만 돌렸을 때 K-Beauty 키워드 효과는 +8.43%p 가 나왔습니다. 그러나 신뢰구간이 [2.46, 14.15] 로 매우 넓었고(p < 0.05 라도 추정 폭이 넓다는 뜻), TikTok 의 viral 특성상 ERV 상위 1% extreme(132% 등) 이 평균을 끌어올린 결과였습니다.

윈저화(winsorization, 상위 1% 를 임계치로 cap) 99% 적용 후 OLS HC3 (heteroskedasticity-consistent 표준오차, 분산 불균형 보정) 로 재추정하니 **+5.10%p (상한)** 으로 안정화됐고, 조건이 비슷한 영상끼리 1:1 매칭하는 PSM (Propensity Score Matching, 처치군과 비슷한 통제군을 짝지어 confounder 효과 제거) 으로 ATT (Average Treatment Effect on Treated, 처치군의 평균 인과 효과) 를 구하니 **+4.76%p (하한)** 가 나왔습니다. 두 추정 차이가 0.34%p 미만이라 K-Beauty 효과는 **4.76 ~ 5.10%p 구간** 으로 robust 하다고 결론냈습니다. *단순 OLS 의 8.43 만 보고 결론냈다면 두 배 가까이 과대 추정한 권고를 했을 것* — 인과 보강이 분석가의 책임이라는 걸 직접 확인한 경험이었습니다.

자세한 수치 변천 기록: [`docs/refactor/14_kpremium_number_history.md`](../docs/refactor/14_kpremium_number_history.md).

### 2-3. 왜 추천 알고리즘을 ver.1 → ver.4 까지 진화시켰나 — 자기 비판 closed loop

K-Beauty 효과가 인플루언서 selection (누가 만드는가) 에 크게 의존한다는 점을 확인했기 때문에, 인플루언서를 자동으로 선정하는 추천 알고리즘이 직접적인 솔루션이라고 봤습니다.

콘텐츠 토픽(LDA top3 태그) + 인플루언서 ER% 가중치를 결합한 TF-IDF (Term Frequency-Inverse Document Frequency, 문서별 단어 중요도 가중치) + cosine similarity (벡터 방향 유사도) 기반으로 ver.1~ver.3 을 진화시켰는데, ver.3 결과를 stability 검증(1,540 selected pair 비교) 했더니 단일 selected 결과가 lucky case 였고 평균은 무작위 대비 1.25× 에 그쳤습니다. ER% 가중치 메커니즘 자체가 의도대로 작동하지 않은 것 — `int(round(...))` 의 정보 손실로 56명 중 47명(84%) 이 동일한 (1,1,1) 가중치가 되는 — 을 발견했습니다.

ver.4 에서 TF inflation (단어 N번 반복) 을 제거하고 score 단계의 연속 가중치 곱셈(`score = sim × (normalized_ER + 0.1)`) 으로 재구현했더니 평균 **3.25× random** (Top-10), Precision@10 **60%** (vs ver.3 20%), paired t-test t=122.80 (p<0.0001) 로 정량 개선됐습니다. *자기 비판 → 개선 → 검증* 의 closed loop 으로 알고리즘 신뢰도를 직접 입증한 경험이었습니다.

## 3. 프로젝트 결과 — "K-Beauty 키워드 +4.76~5.10%p · 1만뷰당 47,600~51,000원, 추천 알고리즘 무작위 대비 3.25배 ER%"

K-Beauty 해시태그 효과는 통제 회귀와 인과 보강 양쪽에서 일관되게 나왔습니다.

- **OLS HC3 (상한)**: 조회수·팔로워·계정 규모를 통제한 후에도 K-Beauty 키워드는 ERV 를 평균 **+5.10%p (p<0.05)** 상승시킵니다.
- **PSM ATT (하한)**: 영상 특성이 비슷한 K-Beauty vs Generic Skincare 1:1 매칭 후에도 효과가 **+4.76%p (p<0.05)** 유지됩니다.
- **1만뷰 환산**: 참여 1건당 100원 가정 시 1만뷰당 추가 가치 **47,600 ~ 51,000원** (PSM 하한 ~ OLS 상한). 시나리오 민감도(100/300/1,000원) 도 함께 제공해 마케팅 부서의 budget 시나리오에 직접 적용 가능하게 했습니다.

추천 알고리즘 ver.4 는 1,540개 인플루언서 조합으로 stability 검증한 결과:

| Metric | ver.3 | ver.4 | 개선 |
|---|---:|---:|---:|
| 1,540 pair 평균 ER% | 15.0 | **39.1** | +24.1 |
| × random (10000 부트스트랩) | 1.25× | **3.25×** | — |
| > random 비율 | 61.4% | **100%** | — |
| Precision@10 | 20% | **60%** | — |

Paired t-test (v4 - v3): t=122.80, p<0.0001 — 모든 selected 조합에서 ver.4 가 ver.3 능가.

## 4. 프로젝트 회고

이번 프로젝트에서는 *통계적 효과 = 인과 효과* 가 아니라는 걸 분석 단계마다 직접 확인하면서 진행한 경험이 가장 컸습니다.

### 배운 점

대표적인 두 사례가 있습니다.

첫 번째는 **윈저화(winsorization) 적용 여부에 따라 효과 크기가 8.43→5.10%p 로 달라진 일** 이었습니다. TikTok 데이터의 viral 특성상 ERV 가 100%를 넘는 영상이 1% 정도 섞여 있었는데, 그게 평균을 끌어올려 단순 OLS 결과를 과대 추정했습니다. 윈저화 99% (상위 1% 를 임계치로 cap) 한 뒤에는 신뢰구간도 [3.68, 6.35]로 좁아지고 추정도 안정됐습니다. *데이터 분포의 꼬리부터 보는 습관* 이 그때 생긴 것입니다.

두 번째는 **추천 알고리즘 ver.3 의 가중치가 의도대로 작동하지 않은 일** 입니다. ER% MinMax 정규화 후 `int(round(normalized_ER * 3))` 로 콘텐츠 키워드 가중치를 줬는데, 56명 인플루언서 중 **47명(84%)** 의 가중치가 0이 되어 전부 `max(1, ...)` 안전장치로 동일한 (1,1,1) 가중치가 되었습니다. 즉 ver.3 = ver.2 와 사실상 같은 알고리즘이었습니다. 이걸 발견한 뒤 ver.4 에서는 TF 반복(inflation) 대신 score 단계의 연속 가중치 곱셈으로 바꾸니 1,540 pair 평균 1.25× → 3.25× random 으로 정량 개선됐습니다. *알고리즘의 의도와 실제 작동을 정량으로 분리해서 검증해야 한다* 는 걸 그때 배웠습니다.

### 한계

인과 추정 측면에서 추가 검증을 진행한 결과, 같은 인플루언서가 K-Beauty / non-K-Beauty 영상 둘 다 만든 케이스만 비교(within-influencer fixed effect, 인플루언서 고유 특성을 통제하는 회귀 기법) 했더니 K-Beauty 키워드 자체의 효과는 **+0.24%p (p=0.75, 통계적 유의 X)** 로 떨어졌습니다 — 즉 OLS·PSM 의 4.76~5.10%p 효과의 약 95% 가 *인플루언서 selection effect* (특정 그룹에 원래부터 인기 있는 사람이 몰린 편향) 라는 추가 발견입니다. 본 결과는 "조건이 비슷한 영상끼리 비교했을 때의 효과" 까지가 robust 한 추정 한계이고, 인플루언서 자체의 채널 컨셉·팔로워 충성도까지 통제한 효과는 향후 표본 확대 후 재검증이 필요합니다 (자세히는 [`docs/refactor/14_kpremium_number_history.md`](../docs/refactor/14_kpremium_number_history.md)).

또 단일 시점·단일 데이터셋(2024.12 수집) 이라 다른 기간으로 일반화하려면 추가 수집이 필요합니다. TikTok 데이터는 CAPTCHA·로그인 등 플랫폼 보안으로 완전 자동 수집이 어려워 표본 크기 확장 자체가 비용입니다.

모르는 부분을 모른다고 적어두는 것이 다음 분석에서 같은 추정 함정을 반복하지 않는 출발점이라고 봤습니다.

## 5. 이 프로젝트로 얻은 것

이번 프로젝트로 데이터 분석가 직무의 핵심 흐름 — *비즈니스 질문 → 데이터 가설 → 인과 추정 → 정량 환산 → 액션 알고리즘* — 을 한 사이클로 돌려본 경험을 했습니다. K-Beauty 라는 비즈니스 개념을 ERV 라는 측정 가능한 지표로 옮기고, OLS·PSM 으로 효과 구간을 산출한 뒤, 인사이트를 인플루언서 시딩 추천 알고리즘으로 자동화했습니다. 마지막에는 1,540 selected pair stability 검증으로 알고리즘 자체의 robustness 까지 정량 입증했습니다.

데이터 분석가 직무에서 가장 중요한 건 *통계적 효과를 그대로 권고로 옮기지 않고, 인과 보강과 robustness 검증으로 의사결정의 신뢰도를 직접 끌어올리는* 일이라고 봅니다. 이번에 그 흐름을 직접 한 번 끝까지 돌려본 만큼, 다른 도메인의 비즈니스 질문에도 같은 방식으로 접근할 수 있다고 봅니다.

특히 어떤 분포의 데이터를 어떻게 다듬을지 (윈저화), 어떤 confounder 를 어떻게 통제할지 (PSM), 자기 알고리즘의 한계를 어떻게 정량으로 발견할지 (stability 검증) — 이 세 가지는 어떤 도메인의 데이터를 다뤄도 공통으로 필요한 분석가의 기본기라고 봅니다.

## 6. 사용 기술과 협업 역량

**Hard skills**

- 데이터·통계: Python, Pandas, NumPy, scikit-learn, statsmodels (회귀·인과 추정), gensim (LDA 토픽 모델), nltk·spaCy (NLP)
- 추천 알고리즘: TF-IDF + cosine similarity, PMI (Pointwise Mutual Information, 단어 공출현 정보 점수), MinMax 정규화, 부트스트랩 stability 검증 (10,000회 재추출)
- 데이터 수집: Selenium (Amazon), TikTok 반자동 (CAPTCHA 수동)
- DB·인프라: MySQL (SQLAlchemy upsert), Slack 모니터링, Docker
- LLM·지식그래프: GraphRAG (LanceDB + Ollama·OpenAI), pyLDAvis 시각화

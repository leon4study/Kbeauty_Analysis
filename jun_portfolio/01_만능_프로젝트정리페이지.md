# K-Beauty 미국 시장 진출 전략 분석 - 김현준

| 기간 | 역할 | 팀 | 결과 |
| --- | --- | --- | --- |
| 2024.12.17 ~ 2024.12.27 (2주) | 팀원 : 인과 추론·추천 알고리즘 주도 | 5명 (분석 4, 발표 1) | K-Beauty 키워드 ERV 프리미엄 +4.76~5.10%p (1만뷰당 47,600~51,000원) |

## "TikTok 마케팅의 ‘느낌상 효과’를 K-Beauty 키워드 +4.76~5.10%p, 1만뷰당 47,600~51,000원의 정량 가치로 환산했습니다"

Amazon 리뷰(정성)와 TikTok 영상 반응(정량/행동) 두 종류의 데이터를 같은 의사결정에 묶어 K-Beauty 미국 시장 진입 전략을 데이터로 검증한 프로젝트입니다. 단순 회귀로 끝낸 게 아니라, 인과 추론 보강(PSM)으로 효과 구간을 산출하고 인플루언서 시딩 추천 알고리즘까지 직접 만들어 정량 효과를 검증한 점이 핵심입니다. 5명 팀의 분석 파트로 인과 추정·추천 알고리즘 진화 전반을 주도했습니다.

---

## 1. 문제 정의 — "‘TikTok 마케팅이 효과 있다’는 정성 평가를, 인과 추정으로 정량값까지 끌어내려 했습니다"

K-Beauty 브랜드의 미국 진출에서 흔히 듣는 조언은 *"TikTok 으로 입소문 나면 Amazon 매출도 따라온다"* 입니다. 그러나 실제 효과 크기는 합의된 수치가 없습니다. 마케팅 부서가 인플루언서 시딩(seeding)에 예산을 얼마 써야 하는지, 어떤 인플루언서를 어떤 키워드로 골라야 하는지 — 이 질문에 답할 정량 근거가 부족했습니다.

문제는 단순히 "K-Beauty 키워드를 쓴 영상의 평균 ERV (Engagement Rate per View, 조회수 대비 좋아요·댓글·저장 합) 가 높다" 는 비교만으로는 인과 효과로 보기 어렵다는 점이었습니다. K-Beauty 키워드를 쓰는 인플루언서들이 *원래부터* 인기 있는 사람들일 가능성을 통제해야 했습니다. 단순 OLS 회귀에 그치지 않고 인과 추론까지 단계적으로 보강하는 분석 설계가 필요했습니다.

## 2. 해결 방법 — "두 데이터를 한 의사결정으로 묶고, 인과 추정 단계를 단계적으로 쌓았습니다"

먼저 데이터 수집부터 직접 했습니다. Amazon 5개 K-Beauty 브랜드(COSRX, PURITO, Beauty of Joseon, imfrom, Dr.Jart+) 의 제품·리뷰를 Selenium 으로 1.2만 건 수집했고, TikTok 영상은 K-Beauty / 일반 스킨케어 해시태그 기반으로 56명 인플루언서의 1,680 영상을 반자동(CAPTCHA 수동 통과) 수집했습니다.

분석 파이프라인은 5단계로 설계했습니다.

① 그룹 분류 — `K-Beauty / Generic Skincare / Others` 3-그룹으로 분리 (같은 카테고리 안 비교)
② 지표 생성 — `ERV` 계산 + 윈저화(상위 1% 캡) + 로그 변환 (`log_view`, `log_follower`)
③ 통제 회귀 (OLS, HC3 robust SE) — 조회수·팔로워 통제 후 K-Beauty 효과
④ 인과 보강 (PSM ATT) — 영상 특성(`log_follower, log_view, upload_gap`)이 비슷한 K-Beauty vs Generic Skincare 1:1 매칭 후 ATT
⑤ 1만뷰 기준 금액 환산 + 시나리오 민감도

실행 과정에서 가장 중요한 의사결정 세 가지를 짚으면 다음과 같습니다.

### 2-1. 왜 두 데이터(Amazon + TikTok)를 같이 보았나 — 정성·행동의 상호 보완

Amazon 리뷰는 *사용 경험* 의 심층 표현(만족·불만·성분 호불호) 이고, TikTok 은 *인지·반응* 의 광범위 신호(조회·참여·해시태그) 입니다. 한쪽만 보면 시장의 절반만 보는 셈이라, 두 데이터를 토픽·키워드 단위로 연결해서 *어떤 콘텐츠 메시지가 실제 구매 만족과 일치하는지* 검증하는 구조로 설계했습니다.

### 2-2. 왜 단순 OLS 가 아닌 PSM 까지 갔나 — 인과 보강의 단계적 접근

처음 단순 회귀만 돌렸을 때 K-Beauty 키워드 효과는 약 +8.43%p 가 나왔습니다. 그러나 신뢰구간이 [2.46, 14.15]로 매우 넓었고, TikTok 의 viral 특성상 ERV 상위 1% extreme(132% 등) 이 평균을 끌어올린 결과였습니다.

윈저화(winsorization) 99% 적용 후 OLS HC3 (heteroskedasticity-consistent 표준오차) 로 재추정하니 **+5.10%p (상한)** 으로 안정화됐고, 조건이 비슷한 영상끼리 1:1 매칭하는 PSM (Propensity Score Matching) 으로 ATT 를 구하니 **+4.76%p (하한)** 가 나왔습니다. 두 추정의 차이가 0.34%p 미만이라 K-Beauty 효과는 **4.76 ~ 5.10%p 구간** 으로 robust 하다고 결론냈습니다. *단순 OLS 만 보고 결론 냈다면 8.43%p 라는 과대 추정으로 마케팅 권고를 했을 것* — 이게 인과 보강의 가치였습니다.

추가로 같은 인플루언서가 K-Beauty / 그 외 영상을 모두 만든 경우만 비교하는 within-influencer fixed effect 까지 돌렸더니 K-Beauty 키워드 자체의 효과는 **+0.24%p (p=0.75, 통계적 유의 X)** 로 떨어졌습니다. 즉 OLS·PSM 의 4.76~5.10%p 효과의 약 **95%는 *원래부터 ERV 가 높은 인플루언서들이 K-Beauty 키워드를 쓰는 데서 오는 효과*** 라는 점이 보였습니다. *키워드 자체의 마진* (인플루언서 신규 시딩 시) 4.76~5.10%p, *키워드 단독 효과* (같은 인플루언서가 키워드 추가 시) 0.24%p — 두 결과를 분리해서 해석해야 한다는 게 본 분석의 핵심 인사이트였습니다.

자세한 수치 변천 기록: [`docs/refactor/14_kpremium_number_history.md`](../docs/refactor/14_kpremium_number_history.md).

### 2-3. 추천 알고리즘을 네 번에 걸쳐 개선한 경험 — 조합 검증에서 발견한 한계를 보완해 성능 향상

K-Beauty 효과가 인플루언서 selection(누가 만드는가) 에 크게 의존한다는 점을 분석에서 확인했기 때문에, 인플루언서를 자동으로 선정하는 추천 알고리즘이 직접적인 솔루션이라고 봤습니다.

처음 만든 알고리즘은 콘텐츠 토픽(LDA top3 태그) + 인플루언서 효율(ER%) 가중치를 결합한 TF-IDF (Term Frequency-Inverse Document Frequency, 문서별 단어 중요도 가중치) + cosine 유사도 기반이었습니다. 결과를 1,540개 조합 (56명 중 2명을 기준 인플루언서로 뽑는 모든 경우의 수) 으로 확인해보니 처음에 본 단일 결과(무작위 대비 2.32배) 가 운 좋게 잘 나온 케이스였고, 1,540개 평균은 무작위 대비 1.25배에 그쳤습니다.

원인을 자세히 살펴보니, ER% 가중치(`int(round(...))`) 가 의도와 다르게 작동했습니다. 56명 중 47명(84%) 이 가중치가 0이 되어 안전장치 발동으로 모두 동일한 (1,1,1) 가중치가 됐고, 결과적으로 ER% 가중치가 거의 작동 안 한 셈이었습니다.

이 부분을 보완해서 단어 반복 방식 대신 점수를 계산할 때 직접 ER% 를 곱하는 방식 (`score = sim × (ER% + 0.1)`) 으로 다시 만들었더니 평균 **3.25배 random** (Top-10), Precision@10 **60%**, paired t-test t=122.80 (p<0.0001) 로 정량 개선됐습니다. 1,540개 조합 검증으로 한계를 발견하고 다시 만든 흐름으로 알고리즘 신뢰도를 직접 끌어올린 작업이었습니다.

## 3. 프로젝트 결과 — "K-Beauty 키워드 +4.76~5.10%p · 1만뷰당 47,600~51,000원, 추천 알고리즘 무작위 대비 3.25배 ER%"

K-Beauty 해시태그 효과는 통제 회귀와 인과 보강 양쪽에서 일관되게 나왔습니다.

- **OLS HC3 (상한)**: 조회수·팔로워·계정 규모를 통제한 후에도 K-Beauty 키워드는 ERV 를 평균 **+5.10%p (p<0.05)** 상승시킵니다.
- **PSM ATT (하한)**: 영상 특성이 비슷한 K-Beauty vs Generic Skincare 1:1 매칭 후에도 효과가 **+4.76%p (p<0.05)** 유지됩니다.
- **1만뷰 환산**: 참여 1건당 100원 가정 시 1만뷰당 추가 가치 **47,600 ~ 51,000원** (PSM 하한 ~ OLS 상한). 시나리오 민감도(100/300/1,000원) 도 함께 제공.

최종 알고리즘은 1,540개 인플루언서 조합으로 결과 일관성을 확인했더니 다음 결과를 얻었습니다.

| 지표 | 처음 만든 알고리즘 | 다시 만든 알고리즘 | 개선 |
|---|---:|---:|---:|
| 1,540 조합 평균 ERV | 15.0 | **39.1** | +24.1 |
| 무작위 대비 (10,000회 부트스트랩) | 1.25배 | **3.25배** | — |
| 무작위 평균 이상 비율 | 61.4% | **100%** | — |
| 정확도 Precision@10 | 20% | **60%** | — |

같은 selected 짝 비교(paired t-test) 에서 t=122.80, p<0.0001 — 1,540개 조합 모두에서 다시 만든 쪽이 더 잘 나왔습니다.

### 마케팅 권고 액션

분석 결과를 바탕으로 마케팅 부서가 바로 적용할 수 있는 권고를 정리했습니다.

- **신규 인플루언서 시딩 시 K-Beauty 키워드 사용자 우선** — 4.76~5.10%p 효과가 인플루언서 selection 에 의존하므로, 같은 카테고리 안에서 *이미 K-Beauty 콘텐츠를 만든 적 있는* 인플루언서를 시딩 풀에 우선 포함
- **세그먼트별 차별 접근 권장** — 추천 알고리즘 결과를 마이크로(10K-100K), 미들(100K-500K), 매크로(>1M) 로 분리해 캠페인 목표(인지도/전환/Brand awareness)에 맞춰 운영
- **1만뷰당 47,600~51,000원** 은 ERV (참여 행동) 기준 하한 추정 — Amazon 실제 매출 funnel 까지 가는 conversion 은 별도 측정 필요. *참여 → 검색 → Amazon 구매* 의 추적 데이터가 추가되면 ROAS / CAC 같은 표준 KPI 환산 가능

### 한계

본 분석의 한계는 두 가지입니다.

첫째, 단일 시점·단일 데이터셋(2024.12 수집) 이라 다른 기간으로 일반화하려면 추가 수집이 필요합니다. TikTok 데이터는 CAPTCHA·로그인 등 플랫폼 보안으로 완전 자동 수집이 어려워 표본 크기 확장 자체가 비용입니다.

둘째, ERV (참여) 가 *직접 매출* 이 아닌 *관심·반응 신호* 까지만 측정합니다. TikTok → Amazon 로 가는 attribution (구매 출처 추적) 데이터가 없어 1만뷰당 47,600~51,000원은 *참여 가치를 마케팅 비용으로 환산했을 때의 비교 기준* 까지가 한계입니다.

## 4. 프로젝트 회고 — 분석 단계마다 직접 확인하면서 배운 것

이번 프로젝트에서는 *통계적 효과 = 인과 효과* 가 아니라는 걸 분석 단계마다 직접 확인하면서 진행한 경험이 가장 컸습니다.

### 배운 점

대표적인 두 사례가 있습니다.

첫 번째는 **윈저화(winsorization) 적용 여부에 따라 효과 크기가 8.43→5.10%p 로 달라진 일** 이었습니다. TikTok 데이터의 viral 특성상 ERV 가 100%를 넘는 영상이 1% 정도 섞여 있었는데, 그게 평균을 끌어올려 단순 OLS 결과를 과대 추정했습니다. 윈저화 99% (상위 1% 를 임계치로 cap) 한 뒤에는 신뢰구간도 [3.68, 6.35]로 좁아지고 추정도 안정됐습니다. 데이터의 극단값을 먼저 봐야 한다는 걸 그때 제대로 체감했습니다.

두 번째는 **처음 만든 추천 알고리즘의 가중치가 의도대로 작동하지 않은 일** 입니다. ER% MinMax 정규화 후 `int(round(normalized_ER * 3))` 로 콘텐츠 키워드 가중치를 줬는데, 56명 인플루언서 중 **47명(84%)** 의 가중치가 0이 되어 전부 안전장치로 동일한 (1,1,1) 가중치가 되었습니다. 즉 ER% 가중치가 거의 작동 안 한 상태였습니다. 단어 반복 방식 대신 점수 계산 단계에서 ER% 를 직접 곱하는 방식으로 다시 만드니 1,540 조합 평균 1.25배에서 3.25배 무작위 대비로 정량 개선됐습니다. *알고리즘이 의도대로 작동하는지 작동 방식까지 직접 확인해야 한다* 는 걸 그때 배웠습니다.

### 분석 한계

본 분석의 한계 두 가지는 §3 마지막에 정리했고, 데이터 적용 측면에서 추가로 의식한 한계는 아래 두 가지입니다.

- **추천 알고리즘 평가 metric 보강 여지**: 본 분석은 1만뷰당 ERV 평균과 Precision@10 으로 평가했지만, NDCG·MAP·HitRate 같은 ranking quality 표준 metric 도 같이 보면 알고리즘 우위를 더 robust 하게 입증 가능. 후속에서 추가 적용 예정.
- **추천 풀 크기**: 본 데이터의 인플루언서 56명은 작은 규모. 실제 KOL 캠페인은 수백~수천명 풀에서 추천이 의미 — 데이터 확장 후 알고리즘 scaling 검증 필요.

모르는 부분을 모른다고 적어두는 것이 다음 분석에서 같은 추정 함정을 반복하지 않는 출발점이라고 봤습니다.

## 5. 이 프로젝트로 얻은 것

이번 프로젝트로 통계 분석에서 효과 추정부터 인과 보강, 마케팅 효과 계산, 액션 알고리즘까지 한 흐름으로 끌고 가는 경험을 했습니다. K-Beauty 키워드라는 비즈니스 개념을 ERV 라는 측정 가능한 지표로 바꾸고, OLS·PSM 으로 효과 구간을 산출한 뒤, 그 인사이트를 인플루언서 시딩 추천 알고리즘으로 자동화했습니다. 마지막에는 1,540개 인플루언서 조합으로 알고리즘 결과 일관성까지 정량으로 확인했습니다.

데이터 분석가 직무에서 가장 중요한 건 *비즈니스 질문을 데이터 가설로 옮기고, 가설을 인과적으로 검증한 뒤, 결과를 액션 가능한 솔루션으로 풀어내는 흐름* 이라고 봅니다. 이번에 그 한 사이클을 처음부터 끝까지 돌려본 만큼, 다른 도메인의 비즈니스 질문에도 같은 방식으로 접근할 수 있다고 봅니다.

특히 — 윈저화로 극단값 다루기, PSM 으로 인과 보강하기, 추천 알고리즘이 의도대로 작동하는지 작동 방식까지 직접 확인하기 — 이 세 가지는 어떤 도메인의 데이터를 다루더라도 공통으로 필요한 분석가의 기본기라고 봅니다.

## 6. 담당 역할과 사용 기술

**직접 설계·구현한 부분**

- 데이터 수집·크롤러: Selenium 으로 Amazon 5 brand 1.2만 건 직접 크롤링, TikTok 56명 1,680 영상 반자동 수집 (CAPTCHA 수동 통과 포함)
- DB·인프라: MySQL 스키마 설계 + SQLAlchemy upsert 로직 작성, Slack 모니터링 봇 연결, Docker 환경 구성
- 인과 추정: 윈저화 + OLS HC3 + PSM ATT + within-influencer fixed effect 까지 4 단계 회귀 작성 (statsmodels)
- 추천 알고리즘: TF-IDF + cosine 유사도 + ER% 가중치 결합 → 1,540 조합 부트스트랩 검증 → 한계 발견 후 다시 구현
- LLM·지식그래프: GraphRAG (LanceDB + Ollama·OpenAI) 환경 구성, pyLDAvis 토픽 시각화

**팀원 분담**: 분석 결과 시각화 (대시보드 일부), 발표 자료 디자인, 일부 토픽 라벨링 검수

**Hard skills**: Python · Pandas · NumPy · scikit-learn · statsmodels · gensim · nltk · spaCy · Selenium · MySQL · SQLAlchemy · Docker · GraphRAG · LanceDB

**Soft skills**

- 단순 OLS (8.43%p) 에서 멈추지 않고 PSM·within-FE 까지 거친 뒤 팀에 효과 구간(4.76~5.10%p) 과 selection 효과(95%) 분리해서 보고 — 팀 의사결정 단계에서 과대 추정 차단
- 처음 만든 추천 알고리즘의 한계를 직접 발견 + 문서화한 뒤 다시 만들어 정량 개선 입증
- 분석 결과를 노션 페이지로 정리해 팀과 발표자에게 전달 (가설 H1~H4 → 검증 결과 → 마케팅 시사점 흐름)
